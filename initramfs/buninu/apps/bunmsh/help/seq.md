## seq

Print a numeric sequence.

### Usage

```sh
seq [OPTIONS] [FIRST [INCREMENT]] LAST
```

### Options and forms

- `-s TEXT`, `--separator TEXT`: Set the separator.
- `-t TEXT`, `--terminator TEXT`: Set the terminator.
- `-w`, `--fixed-width`: Accepted, but currently does not pad values.

### Example

```sh
seq 3
```

Output:

```text
1
2
3
```
